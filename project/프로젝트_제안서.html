01 / 왜 이 서비스가 필요한가? 지금 캠퍼스에서 무슨 일이 일어나고 있나

순천대학교 캠퍼스에는 장애인 편의시설이 분명히 존재합니다. 그러나 어디에 있는지, 지금 사용 가능한지를 알려주는 정보가 어디에도 없습니다.

🚾
화장실 정보가 없다
장애인 화장실이 건물 어느 층, 어느 쪽에 있는지 지도에도, 학교 홈페이지에도 나와 있지 않습니다.
🅿️
주차 정보도 없다
장애인 주차구역 위치를 모르면 캠퍼스 입구에서 한참 헤매야 합니다.
🚧
경사로·계단 정보 없음
휠체어로 이동 가능한 경로인지 아닌지 가보기 전까지는 알 수 없습니다.
❌
고장 정보가 공유 안 됨
엘리베이터가 고장 나도 직접 가보기 전까지는 알 수 없어 헛걸음을 합니다.
💬 실제로 있었던 일
"공대 건물에 장애인 화장실이 있다고 해서 갔더니 잠겨 있었어요. 다시 다른 건물로 가야 했는데, 어디에 있는지 몰라서 한참 헤맸습니다." — 재학생 인터뷰
02 / 지금 있는 서비스와 비교 왜 카카오맵으로는 부족한가?

이미 카카오맵, 네이버 지도 같은 훌륭한 서비스가 있습니다. 하지만 이런 서비스들이 해결하지 못하는 문제가 있습니다.

비교 항목 카카오맵 네이버 지도 공공데이터 SC&U (우리 서비스)
장애인 화장실 층별 위치 ✗ ✗ ✗ ✓ 직접 조사
접근 가능 여부 세부 정보
(문 폭, 경사 유무 등)		 ✗ ✗ ✗ ✓ 포함
캠퍼스 내부 경로 안내 △ 일부만 △ 일부만 ✗ ✓ 접근성 경로
고장/불편 실시간 제보 ✗ ✗ ✗ ✓ 가능
데이터 최신성 △ 비정기 △ 비정기 ✗ 수년 단위 ✓ 커뮤니티 갱신
말로 물어보기 (AI 질문) ✗ ✗ ✗ ✓ AI 챗봇
핵심 차이점
기존 서비스는 "있음/없음"만 표시합니다. SC&U는 실제로 이동할 수 있는지까지 알려줍니다. 직접 발로 뛰어 수집한 데이터 + AI가 이 서비스의 핵심 경쟁력입니다.
03 / 우리가 만들 서비스 SC&U가 제공하는 기능

복잡한 기술보다 실제로 사용 가능한 서비스를 먼저 만들겠습니다. 아래 3가지가 핵심입니다.

🗺️
핵심 기능 1
캠퍼스 접근성 지도
카카오맵 위에 장애인 화장실, 주차공간, 엘리베이터, 경사로 위치를 핀으로 표시합니다. 핀을 누르면 "전동휠체어 진입 가능", "문 폭 90cm" 같은 세부 정보가 나옵니다. 팀이 직접 현장 조사한 데이터를 사용합니다.
📢
핵심 기능 2
실시간 불편 제보 시스템
엘리베이터가 고장났거나, 화장실 문이 잠겼거나, 공사로 통로가 막혔을 때 사용자가 직접 제보할 수 있습니다. 제보는 지도에 바로 반영되어 다른 사용자가 확인할 수 있습니다.
🤖
핵심 기능 3 (차별점)
AI에게 말로 물어보기
지도를 찾아보기 어려운 분들을 위해 채팅으로 질문할 수 있습니다. "도서관 근처 장애인 화장실 어디야?"라고 물어보면 AI가 데이터베이스를 검색해서 바로 답해줍니다.
04 / AI 기능은 어떻게 동작하나? 말로 물어보면 AI가 직접 찾아준다
🤖 AI 챗봇 실제 대화 예시
복잡한 지도를 찾지 않아도, 그냥 말로 물어보면 됩니다
도서관 1층에 휠체어로 들어갈 수 있는 화장실 있어?
네! 도서관 1층 정문 기준 오른쪽 복도 끝에 장애인 화장실이 있습니다. 전동휠체어도 진입 가능한 크기(문폭 95cm)입니다. 단, 지난주 사용자 제보에 따르면 자동문이 느리게 작동 중이라고 합니다.
공대 건물 중에 장애인 주차장 제일 가까운 데가 어디야?
공대 2관 정문에서 약 30m 거리에 장애인 지정 주차구역(3면)이 있습니다. 경사로가 있어 휠체어로 바로 진입 가능합니다.

※ 이 기능은 데이터베이스에 저장된 실제 현장 조사 정보를 AI가 읽어서 답변하는 방식입니다. 허구의 정보를 만들어내지 않고, 팀이 직접 수집한 데이터만 사용합니다.

05 / 개발 계획 1년 동안 단계별로 만들어갑니다
1
1~3개월차
데이터 정리 & 기초 시스템 구축
현장 조사한 데이터를 체계적으로 데이터베이스에 입력. 지도에 핀 표시하는 기본 기능 완성.
2
4~6개월차
제보 시스템 & 사용자 기능
불편 제보 기능, 사용자 로그인, 관리자 승인 시스템 개발.
3
7~9개월차
AI 챗봇 연동
말로 물어보는 AI 기능 개발 및 실제 데이터와 연동. 정확도 테스트.
4
10~12개월차
실제 사용자 테스트 & 발표
장애 학생·교직원 대상 테스트, 피드백 반영, 최종 완성 및 발표 준비.
📌 범위에 대한 솔직한 이야기
건물 내부에서 실시간으로 내 위치를 추적하는 기능(GPS가 안 되는 실내 내비게이션)은 이번 프로젝트에 포함하지 않습니다. 이는 대기업도 수억 원을 투자하는 기술입니다. 대신 직접 조사한 정확한 정보를 잘 보여주는 것, 그리고 AI로 쉽게 찾을 수 있게 하는 것에 집중합니다. 이것만으로도 지금 캠퍼스에 없는 서비스입니다.
