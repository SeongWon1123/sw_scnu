# sw_scnu

순천대 SW 튜터링 프로그램 저장소입니다.

## 작업 원칙

- **문서 유지**: `.hwp` / `.hwpx` / `.pdf` 등 안내·양식 파일은 내용을 건드리지 않고 `docs/` 아래에 보관합니다.
- **중요 설정만 수정**: 비밀값·접속 정보는 `.env` 로만 관리합니다. 저장소에는 `.env.example` 템플릿만 둡니다.

## 로컬 Desktop 자료 반영

로컬 경로 `C:\Users\user\Desktop\SW 튜터링 프로그램` 의 자료를 이 저장소에 넣을 때:

1. HWP / PDF 등 문서는 `docs/` 로 복사 (내용 수정 없음)
2. 소스·설정이 있으면 프로젝트 루트에 배치
3. 실제 비밀값은 `.env` 에만 기록 (커밋 금지)
4. 필요한 키 이름은 `.env.example` 에만 추가·정리

```bash
cp .env.example .env
# .env 값을 로컬 환경에 맞게 수정
```

## 보안

| 파일 | Git |
|------|-----|
| `.env` | 커밋하지 않음 |
| `.env.example` | 커밋 (키 이름·예시만) |
| `docs/*.{hwp,hwpx,pdf}` | 커밋 (문서 원본 유지) |
